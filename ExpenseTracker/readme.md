# Python Expense Tracker

A simple command-line Expense Tracker built using Python. This project allows users to record, manage and monitor their expenses across different spending categories, with data saved locally using JSON.

## Features

- **Add Expenses:** Add new expenses with a name, category and cost.
- **Remove Expenses:** Search for and remove existing expenses.
- **View Expenses:** Display recorded expenses organised by category.
- **Category Totals:** Calculate the total spending within each category.
- **Overall Spending:** Calculate the combined total of all recorded expenses.
- **Data Persistence:** Save expenses to a JSON file so data is retained between sessions.
- **Input Validation:** Handle invalid inputs and prevent negative expense amounts.

## Expense Categories

Expenses are organised into four categories:

- Food
- Entertainment
- Utilities
- Housing

## Technologies Used

- Python 3
- JSON
- Built-in Python modules and functions

## Example Usage

```text
---------EXPENSE TRACKER----------

1. Add Expense
2. Remove Expense
3. View Expenses
4. Exit

Select an option:
```

Users can navigate the menu to manage their expenses and view their spending totals.
